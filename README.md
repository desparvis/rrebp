## Description

Rwanda Real Estate Brokers Platform is a web2 and web3 application designed to improve transparency in the Rwandan real estate sector. It has normal web2 features such as authentication, creation, editing, deleting features. These features allow users to register real estate associations, approve the associations, and register brokers locally. This platform also has web3 capabilities as brokers can be recorded on the blockchain to maintain on-chain registry for broker verification.
